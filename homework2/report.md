問題一

Polynomial Class

解題說明

這題是要使用 C++ 的 class 來建立 Polynomial 多項式類別，並完成多項式的基本運算。

多項式裡面會有很多項，每一項都有係數和指數，所以我使用 Term 來儲存這些資料，再利用 Polynomial 類別把它們管理起來。

解題策略

1. 先建立 Term 類別，用 coef 和 exp 儲存係數及指數。
2. 建立 Polynomial 類別，使用 termArray 來存放多項式的資料。
3. 使用 capacity 記錄陣列容量，terms 記錄目前有幾項。
4. 當陣列空間不夠時，就建立更大的陣列，再把原本的資料複製過去。
5. 使用 Add() 來計算兩個多項式相加。
6. 使用 Mult() 來計算兩個多項式相乘。
7. 使用 Eval() 將數值代入多項式，計算最後的結果。

例如：

P(x) = 3x² + 2x + 1

Q(x) = x + 2

相加後：

P(x) + Q(x) = 3x² + 3x + 3

程式實作

使用前面提供的 Polynomial C++ 程式碼。

效能分析

1. 時間複雜度：這份程式在新增多項式項目時，需要檢查有沒有相同指數。加法最壞情況為 O((n+m)²)，乘法因為需要讓兩個多項式的每一項互相相乘，最壞情況為 O(n²m²)。
2. 空間複雜度：使用動態陣列儲存多項式，會隨著項數增加而使用更多記憶體。單一多項式需要 O(n) 空間。

測試與驗證

測試案例	輸入	預期輸出
測試一	(3x²+2x+1)+(x+2)	3x²+3x+3
測試二	(3x²+2x+1)×(x+2)	3x³+8x²+5x+2
測試三	P(x)=3x²+2x+1，x=2	17
測試四	P(x)=0，Q(x)=x+2	x+2

實際輸出需要執行程式後再確認。

編譯與執行指令

g++ -std=c++17 -o polynomial polynomial.cpp
./polynomial

結論

1. 這次使用 class 來建立多項式，讓我比較了解類別可以怎麼儲存和管理資料。
2. 使用動態陣列後，就不用一開始把陣列大小設定得很大。
3. 多項式的加法和乘法需要處理相同指數的項目，這也是這題比較需要注意的地方。
4. 透過這次作業，我對 Polynomial 類別和動態陣列的使用方式更熟悉。

問題二

Polynomial Input and Output

解題說明

這題是要讓 Polynomial 類別可以直接使用 cin 和 cout 來輸入及輸出多項式。

原本需要另外寫函式來輸入和顯示資料，這次則是使用運算子多載，讓程式可以直接用 >> 和 << 來處理。

解題策略

1. 先在 Polynomial 類別裡面加入 >> 和 << 的宣告。
2. 使用 friend，讓這兩個運算子可以讀取類別裡面的資料。
3. 使用 >> 讓使用者輸入多項式的項數。
4. 接著依序輸入每一項的係數和指數。
5. 將輸入的資料存進 termArray。
6. 使用 << 把多項式依照指數大小輸出。
7. 最後在 main() 裡面測試輸入和輸出功能。

例如輸入：

3
3 2
2 1
1 0

輸出：

P(x) = 3x^2 + 2x + 1

程式實作

使用前面提供的 Polynomial 輸入與輸出 C++ 程式碼。

效能分析

1. 時間複雜度：輸入時需要檢查每一項的指數，並將資料放到適當的位置，所以最壞情況為 O(n²)。輸出時只需要把每一項依序顯示出來，因此為 O(n)。
2. 空間複雜度：使用動態陣列儲存輸入的多項式資料，項數越多，需要的空間也越多，所以為 O(n)。

測試與驗證

測試案例	輸入	預期輸出
測試一	(3,2)、(2,1)、(1,0)	3x²+2x+1
測試二	(5,3)、(2,0)	5x³+2
測試三	(4,1)	4x
測試四	0 項	0

實際輸出需要執行程式後再確認。

編譯與執行指令

g++ -std=c++17 -o polynomial_io polynomial_io.cpp
./polynomial_io

效能量測

這題可以透過不同項數的多項式來觀察輸入和輸出所需要的時間。

例如分別測試 10 項、100 項和 1000 項，看看資料量增加後，程式執行時間有什麼變化。

因為輸出到螢幕也需要時間，所以量測時要注意這部分可能會影響結果。

結論

1. 這次使用運算子多載來完成多項式的輸入和輸出。
2. 使用 >> 和 << 後，就可以直接使用 cin 和 cout，程式看起來也比較簡單。
3. 透過這次作業，我比較了解 friend 和運算子多載的使用方式。

申論及開發報告
